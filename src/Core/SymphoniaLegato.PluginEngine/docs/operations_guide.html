SymphoniaLegato.PluginEngine

Operations Guide — plugin host & sandbox

System description

Hosts and sandboxes third-party plugins (instruments, exporters), surfaced through the Desktop app's Plugin Manager dialog.

Prerequisites

.NET 9 SDK. Depends on SymphoniaLegato.Core only.

Build & verify in isolation

dotnet build src\Core\SymphoniaLegato.PluginEngine\SymphoniaLegato.PluginEngine.csproj

No dedicated unit-test project for this module currently.

Log files

None persisted — see root operations guide.

Configuration parameters

Plugin installation/enablement is managed through the Desktop app's Plugin Manager dialog; see docs/PLUGIN_SDK.md for the plugin authoring contract this module exposes.
