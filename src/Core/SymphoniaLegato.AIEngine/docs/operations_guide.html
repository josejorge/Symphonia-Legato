SymphoniaLegato.AIEngine

Operations Guide — chord/fingering analysis & Claude-powered assistance

System description

Split offline/online: ChordDetector and FingeringAdvisor are algorithmic and need no network access. ClaudeAIEngine (the IAIEngine implementation) additionally calls the Claude API for harmonisation, score analysis, and practice recommendations when a key is supplied.

Prerequisites

.NET 9 SDK. Depends on SymphoniaLegato.Core only. Network access + a Claude API key are needed only for the online features.

Build & verify in isolation

dotnet build src\Core\SymphoniaLegato.AIEngine\SymphoniaLegato.AIEngine.csproj

Exercised by SymphoniaLegato.Integration.Tests (Phase 5 AI tests) for the offline chord/fingering paths; the Claude API path is not covered by automated tests (would require network access or mocking).

Log files

None persisted — see root operations guide.

Configuration parameters

The API key does not persist — deliberately. It's typed directly into the Desktop app's AI Assistant sidebar each session. A settings file now exists for other preferences (Services/AppSettingsService.cs, added 2026-09-15), but the API key is intentionally kept out of it rather than written to disk in plaintext — see docs/AUTHENTICATION.md.

Common troubleshooting

SymptomCause / fix
Harmonisation/analysis fails or returns nothingConfirm an API key was entered this session — it resets on every app restart. Offline chord detection and fingering still work with no key.
Build error CS9006 in ClaudeAIEngine.csRaw interpolated string literals with JSON examples: a literal { inside $"""…""" starts an interpolation. Use $$"""…""" instead — a single {/} becomes literal, and {{expr}} is the interpolation (pitfall #15).
