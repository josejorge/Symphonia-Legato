SymphoniaLegato.Core

Operations Guide — domain library

System description

The domain model layer: Score, Part, Staff, Measure, Note, Pitch, and every interface the engine libraries implement. A pure library with no runtime process of its own — it's "operated" by being built and tested as part of the solution.

Prerequisites

.NET 9 SDK only. No third-party package dependencies.

Build & verify in isolation

dotnet build src\Core\SymphoniaLegato.Core\SymphoniaLegato.Core.csproj
dotnet test tests\SymphoniaLegato.Core.Tests --no-build   # 27 tests

Log files

None — this library has no logging surface of its own; consumers log through their own ILogger<T> instances.

Configuration parameters

None. Every consumer constructs domain models directly (or via Score.CreatePianoScore()).

Common troubleshooting

SymptomCause / fix
New score renders blankScore.CreatePianoScore() creates staves with no measures by design — the caller must call editor.AddMeasures(0, 4) afterward (see root CLAUDE.md pitfall #11).
