SymphoniaLegato.Core

Executive Overview — the foundation everything else is built on

What it does, in plain terms

Every piece of Symphonia Legato — the editor, the playback engine, the exporters, the AI assistant — needs a shared, agreed-upon definition of "what is a note," "what is a measure," "what is a score." This module is that shared definition. Nothing plays a sound or draws a note directly; it just defines the vocabulary everything else speaks.

Why it matters

  • Keeps the rest of the app consistent — one definition of a note, used everywhere.
  • Changes here ripple everywhere, so it's kept deliberately small and stable.
  • Makes the codebase easier to extend: a new export format or a new engine only needs to understand this one shared model.
