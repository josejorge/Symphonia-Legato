SymphoniaLegato.ImportExport

Executive Overview — talking to the outside world

What it does, in plain terms

A score is only useful if it can leave the app. This module lets scores come in from and go out to standard formats other software understands (MusicXML, MIDI), plus the app's own save format, and keeps a folder in sync across devices via ordinary cloud-drive folders — no separate account or server needed.

Why it matters

  • MusicXML support means a score isn't locked into this one app — it opens in MuseScore, Finale, and others.
  • Folder-based sync works with whatever cloud drive someone already uses, no new account required.
