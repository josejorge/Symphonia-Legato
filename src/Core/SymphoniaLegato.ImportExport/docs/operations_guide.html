SymphoniaLegato.ImportExport

Operations Guide — file format bridges

System description

Handles every non-image file format the app reads or writes: MusicXML 4.0 import/export, MIDI import, the native .enscore ZIP format, SVG export, and folder-based cloud sync via ScoreSyncService.

Prerequisites

.NET 9 SDK. Depends on SymphoniaLegato.Core. Uses DryWetMidi for MIDI parsing (name collision with domain Note/TimeSignature — always alias, see below).

Build & verify in isolation

dotnet build src\Core\SymphoniaLegato.ImportExport\SymphoniaLegato.ImportExport.csproj

Exercised by SymphoniaLegato.Integration.Tests (49 tests, covering export pipelines and format round-trips).

Log files

None persisted — see root operations guide.

Configuration parameters

The cloud sync folder is chosen by the user each session in the Desktop app's Sync Settings dialog (any locally-synced folder, e.g. OneDrive/Dropbox) — ScoreSyncService itself is stateless and takes the folder path per call.
