SymphoniaLegato.GitIntegration

Operations Guide — per-score version history

System description

ScoreVersionControl wraps LibGit2Sharp to give each score its own commit/restore history, independent of this repository's own git history. Surfaced through the Desktop app's Git History panel.

Prerequisites

.NET 9 SDK. NuGet: LibGit2Sharp. Depends on SymphoniaLegato.Core only.

Build & verify in isolation

dotnet build src\Core\SymphoniaLegato.GitIntegration\SymphoniaLegato.GitIntegration.csproj

Exercised by SymphoniaLegato.Integration.Tests.

Log files

None persisted by this module — see root operations guide. Note: it does create its own hidden git repository under the score's save location to track history; this is separate from any log file.

Configuration parameters

None exposed to the user beyond the Git History panel's commit/restore actions.

Common troubleshooting

SymptomCause / fix
History panel is empty for a scoreVersion history only exists once the score has been saved at least once (which initializes its version-control folder) — an unsaved new score has no history yet.
