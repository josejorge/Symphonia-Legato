SymphoniaLegato.Desktop

Operations Guide — the primary Windows/Linux/macOS editor

System description

The full-featured Avalonia MVVM desktop editor: notation entry, MIDI playback with mixer/metronome, PDF/PNG/SVG/MusicXML/MIDI/.enscore import-export, per-score git history, cloud sync, plugin manager, and the AI assistant panel. This is the same application covered by the project root's own operations guide — see that document for the fuller picture; this page is the module-scoped version for anyone working only in this app.

Prerequisites

.NET 9 SDK (or newer, via global.json's rollForward). A MIDI output device for audible playback.

How to build, run, and verify status

dotnet build SymphoniaLegato.sln -c Debug
dotnet run --project src\Apps\SymphoniaLegato.Desktop --no-build

A successful start shows a window titled Untitled • — Symphonia Legato.

Log files

None persisted — logging is configured with AddDebug() only (Program.cs); output reaches an attached debugger's Output window and nowhere else.

Configuration parameters

Most settings persist via Services/AppSettingsService.cs (%AppData%\SymphoniaLegato\settings.json, added 2026-09-15).

Common troubleshooting

SymptomCause / fix
No sound on PlayPick a device in MIDI/Audio Settings and click Apply — the selection now persists and actually takes effect.
New score opens blankScore.CreatePianoScore() creates empty staves by design; the app must add measures immediately after — if you see this from custom code, call editor.AddMeasures(0, 4).
Window won't drag by its title barDon't set ExtendClientAreaToDecorationsHint on MainWindow — it removes the native title bar (pitfall #12).
