SymphoniaLegato.Android

Operations Guide — Android companion app

System description

A viewer-focused companion app (score viewing, playback, metronome, annotations — not full editing parity with Desktop yet). Shares Rendering's ScoreCanvas so scores look identical to Desktop. Built via its own SymphoniaLegato.Android.sln, excluded from the main solution.

Prerequisites

JDK 21 exactly. JDK 25 does not work (blocked by the Android SDK 35 toolchain); JDK 17+ works in theory but 21 is what the toolchain validates against. The JDK bundled with Android Studio is known-good.
dotnet workload install android   # ~1 GB, one-time

How to build, run, and verify status

dotnet build SymphoniaLegato.Android.sln -c Debug
dotnet publish SymphoniaLegato.Android.sln -c Release -r android-arm64 `
  --self-contained -o publish\android

Verify by deploying the APK to a device/emulator and confirming the bottom-nav shell (MainShellView) appears.

Log files

None persisted from this project directly — use adb logcat for on-device diagnostics, standard for any Android app.

Configuration parameters

None beyond what's shared with Desktop through the common Core libraries (e.g. sync folder, if wired up on this platform).

Common troubleshooting

SymptomCause / fix
Build fails with XAPRAS7023Known issue with Avalonia 11.2.x + Android SDK 35 — see docs/ANDROID.md for the documented workaround.
Build fails citing JDK versionConfirm JDK 21 specifically is what's active — set ANDROID_SDK_ROOT / JAVA_HOME to the SDK and JDK 21 directories, or configure them in the Android project folder (see docs/ANDROID.md).
Building the main solution skips this projectExpected — SymphoniaLegato.sln deliberately excludes Android so Desktop always builds without the workload (pitfall #13). Build SymphoniaLegato.Android.sln instead.
